# Security Policy

## Supported Versions

Security fixes are applied to the latest released version on
[PyPI](https://pypi.org/project/mcap-data-loader/). We recommend always running the most recent
release.

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | :white_check_mark: |
| < 0.3   | :x:                |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, report them privately using one of the following channels:

- Open a [private security advisory](https://github.com/OpenGHz/MCAP-DataLoader/security/advisories/new)
  on GitHub (preferred), or
- Email the maintainer at **1352674740@qq.com** with the details.

Please include as much of the following as you can:

- A description of the vulnerability and its potential impact
- Steps to reproduce, or a proof of concept
- Affected version(s) and environment details
- Any suggested mitigation, if known

## What to expect

- We will acknowledge your report as soon as we are able.
- We will investigate and keep you informed of the progress.
- Once a fix is available, we will release it and credit you in the release notes if you wish.

Thank you for helping keep MCAP Data Loader and its users safe.
