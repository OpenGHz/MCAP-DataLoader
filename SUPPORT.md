# Support

Thanks for using MCAP Data Loader! Here is how to get help.

## Documentation first

- [README](README.md) — installation, quickstart, and LeRobot training integration
- [docs/](docs) — performance analysis and pose post-processing guides
- [examples/](examples) — runnable examples covering common workflows

## Questions and usage help

If the documentation does not answer your question, please open a
[GitHub issue](https://github.com/OpenGHz/MCAP-DataLoader/issues) using the **Question** template,
or start a discussion if the repository has Discussions enabled.

When asking for help, it helps to include:

- What you are trying to do
- What you tried and what happened (including the full error output)
- Your environment: OS, Python version, `mcap-data-loader` version, and — if relevant — your
  LeRobot version
- A minimal config or code snippet that reproduces the problem

## Bug reports and feature requests

- **Bugs:** open an issue with the **Bug report** template.
- **Features:** open an issue with the **Feature request** template.

## Security issues

Please do not file public issues for security problems. See [SECURITY.md](SECURITY.md) for how to
report vulnerabilities privately.
